# open-cookie-database.json

Derived from [jkwakman/Open-Cookie-Database](https://github.com/jkwakman/Open-Cookie-Database)
(Apache License 2.0, see `open-cookie-database.LICENSE.txt`), regrouped by
cookie domain and reduced to the `name` / `purpose` / `duration` fields this
plugin uses to prefill the cookie list when an admin adds or edits a
service. Not auto-updated — refresh periodically by re-running the
conversion against the upstream `open-cookie-database.json`.
